# Brand Z · Zain Rahjeh

Portfolio site. One file (`index.html`), no build step.

## Publish on GitHub Pages
1. Create a public repo named `USERNAME.github.io`.
2. Upload everything in this folder, including `.nojekyll` and `assets/`.
3. Settings > Pages > Deploy from branch > `main` / root.
4. Live at `https://USERNAME.github.io`.

Note: YouTube videos do not play when you open index.html from your computer
(Error 153). They play on the live GitHub Pages site.

## Edit content (search these names in index.html)
- `SHOWREEL` / `PF_REEL`: YouTube ids of the showreel (16:9) and before/after reel (9:16)
- `CASES`: the case files (brief, challenge, what I did, result, media)
- `LONG`, `SHORTS`, `AI`: films, Shorts and AI videos
- `FOLDERS` / `IMAGES`: Drive folders, or image paths in assets/thumbs and assets/ads

## Where media goes
- Videos: YouTube (Unlisted is fine). Paste the id.
- Images (thumbnails, ads, before/after stills): `assets/`, as .webp or .jpg under 300 KB.
